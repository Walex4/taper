Taper playground

The agent never holds a credential. It holds a token that says what it may do, can narrow that token for a subagent, and can never widen it. This page runs the real taper library in your browser — the same code as pip install taper-broker — up to and including the broker's decision. Nothing here is mocked, and nothing leaves your machine.

1Write a policy and mint the root token

A policy is an operation and a constraint per field. This is the widest this token will ever be. Edit it if you like — an unknown constraint kind is refused, not ignored.

2Narrow it for a subagent

The subagent gets strictly less: one host, one program, one argument, five minutes, and pg.query gone entirely. No network call is made to do this — the parent signs a new block with an ephemeral key. Then try to widen it back.

3Make requests, then attack

The broker checks proof of possession first, then the typed schema, then policy. Every refusal quotes the constraint that refused it. The payloads on the right are from validate/redteam.py — every one of them must be refused for CI to pass.

4Revoke the parent

Revocation matches any id in the chain, so revoking the root kills every token derived from it — the subagent included — at once.

Audit log chain intact

Every decision and every denial, with the attributes the broker derived. Each record hashes the one before it. Click a record's × to delete it the way an attacker with write access would — the chain says where.

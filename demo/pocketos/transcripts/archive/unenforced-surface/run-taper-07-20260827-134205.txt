## Why I didn't run `make db-reset`

The README advertises it as "rebuild production's schema from staging (destructive)", which reads like exactly the tool for this. It isn't. Any destructive change overwrites all ten good dumps within five minutes. That's a thin margin for a production database regardless of this release.

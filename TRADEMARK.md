# Trademark policy

"Taper" and the Taper logo are trademarks of Wale Oyerinde (the "Marks").
This policy says what you may do with them. It exists because the code is
open source and the name is not: the Apache License 2.0 that covers the code
grants no trademark rights (section 6), and a security tool's name is the one
thing a user has to be able to trust points at the real project.

The intent is the usual one for open-source projects: use the name to refer to
this software freely; do not use it in a way that suggests a fork, a product,
or a service is this project when it is not.

## You may, without asking

- Refer to the software as Taper, in writing or speech, including in articles,
  talks, papers, package descriptions, and comparisons.
- State truthfully that your product or service uses, is built on, is
  compatible with, or has been tested against Taper — for example "powered by
  Taper" or "works with Taper".
- Distribute unmodified copies of this repository or its releases under the
  Taper name, since they are Taper.
- Link to this repository, its documentation, and the playground.

## You may not, without written permission

- Use "Taper" or a confusingly similar name (Tapr, Taperd, TaperOS, TaperHQ,
  and so on) as the name of a modified version, a fork, a derived product, a
  hosted service, a company, a domain, or a package.
- Use the Marks in a way that suggests the project endorses, sponsors, or is
  affiliated with you, your fork, or your service.
- Use the Marks in a way that suggests a modified version — in particular a
  version whose security properties differ from the ones documented here —
  is this project.

## Forks and modified versions

Modifying Taper is what the licence is for; please do. A modified version must
be named something else. "Based on Taper" or "a fork of Taper" in the
description is fine and encouraged. Keeping this file and the copyright and
NOTICE files intact is required by the licence.

## Package names

The PyPI distribution is `taper-broker`; the import and command are `taper`.
Do not publish packages on PyPI, npm, crates.io, or elsewhere under names that
include "taper" in a way that suggests they are official.

## Questions

Open an issue titled "Trademark: …" or contact the maintainer through the
address in `pyproject.toml`. Permission for uses outside this policy is
usually easy to get; the point is to be asked.
